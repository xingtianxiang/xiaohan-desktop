# 小汉桌面宠物

双击 **启动小汉.vbs**。默认只有透明背景的小汉，不打开客户端大窗口。

本地工作版支持在公园和雪地直接喂饭、喝水和休息。已经扔出的球完成后照常计数，途中出现的新需求会在下次扔球时检查。接球界面可以回到原来的出游场景继续散步。桌面上的「更多 → 暂时收起」会把小汉收成屏幕边的一枚按钮，点「叫回小汉」即可回到上次的位置。

本轮 Windows 单元测试通过 57 项，跳过 macOS 专用检查 1 项。独立窗口通过桌面主流程 74 项、接球 72 项、出游和位置恢复 42 项、需求 47 项、如厕 27 项。回归用的模拟存档与结果位于 `work/desktop-qa/local-care-return`。

本地工作版的“更多”首页保留小零食、扔球、散步、轻拍和暂停，成长、照顾状态和设置可单独打开。每页右上都有“× 关闭”，也可按 Esc。零食用单独的接饼干动作。喂饭、喝水和小睡在原画上做连续的小幅动作，保留食盆、水碗和着地的爪子位置。首页截图在上一级 `小汉-更多面板.png`。

更多面板精简时的窗口验证记录在 `work/desktop-qa/compact-care`。最初的主流程检查未能把焦点切到测试背景窗，改用独立测试浮窗后通过。

本地工作版已更新捡球和回程。小汉先撑住前爪，低头咬住球，再转身跑回。回程使用四张叼球跑姿，换步时按支撑爪定位，爪下的近影跟随接触处。到达后小汉减速、站稳、低头放球。预览为上一级 `小汉-爪垫落地.gif`。用户确认出新版时再制作下载包。

动作图按三个年龄和三套服装分别制作，制作入口为 `work/build_fetch_gait.py`，运行时按需读取对应的 PNG 图集。公园和雪地共抽查 2,232 帧，支撑爪的可见边缘距地面基准线最多 1 像素。另有 576 帧嘴部与球位置检查，Windows 独立窗口通过 68 项交互检查。复核入口在 `work/desktop-qa/paw-ground` 和 `work/desktop-qa/fetch-gait`。

最近一次打包（2026-11-16）的 Windows 和 Mac 应用包放在上一级 **小汉-扔球更新** 文件夹，不含之后加入的拔河连击、跳舞、退出告别和存档修复。Windows 10/11 的 Intel/AMD 64 位系统使用 Windows64 ZIP，完整解压后进入“小汉”文件夹，双击 **小汉.exe**。已有便携版先退出，更新时保留原有 data 文件夹。三种包都自带运行环境。

Mac 版适用于 macOS 15 及以上，M 系列使用 arm64，Intel 使用 x86_64。解压后打开小汉.app，沿用应用外的存档。分享版使用 ad-hoc 签名。2026-11-16 的扔球更新已通过双架构云端构建、解压启动与存档复开检查。出游时松手即出球，小汉按距离调整步频，绕小弧线转身，叼球跑回后继续散步。三平台校验记录在 `verification-fetch-continuity.json`，同起点同力度的预览为上一级 `小汉-扔球动作对比.gif`。

## 怎么陪她玩

- 桌面模式把鼠标移到小汉身上，旁边会出现九宫格图像按钮。菜单底部直接显示饱腹、水分和体力，点状态条可打开完整的照顾状态。移出宠物和菜单区域约 0.45 秒后收起。
- 食盆：喂一餐。水滴：喝水。如厕垫：上厕所。爱心：摸摸。红绳：打开「拔玩具」。
- 衣服：打开身边的小衣柜，选择蓝色胸背、红色领巾或暖黄背心；三套装扮覆盖待机、吃喝、玩耍、睡觉、走路和打字。
- 树木：弹出带当前年龄和衣服预览的公园/雪地卡片，点击卡片进入。选择页可用 × 或 Esc 收起，Tab 后按回车或空格也能选卡片。
- 月亮：睡一小觉。“更多”打开宠物旁的小面板。首页显示常用互动，有互动时出现“结束互动”。“成长”中可以看进度和切换形态，“照顾状态”中可以看饱腹、水分、体力、心情和如厕，“设置”中可以开关跟打字、火光和休息提醒，也可以退出小汉。
- 从「更多 → 设置 → 退出小汉」退出时，先保存游戏进度，然后小汉用当前体型和衣服低头、摇尾巴，留下一句「回头见！」。告别约 2.2 秒，最后缩小并关窗。预览为上一级 `小汉-退出告别.gif`，Windows 实窗验证记录在 `work/desktop-qa/farewell/window`。
- “更多 → 暂停陪伴”会停止打字联动、火光、成长和需求计时。闲置时小汉趴下休息，互动中停在当前动作帧。点小汉身下的“继续陪伴”可从暂停的位置继续。正按着鼠标蓄力时暂停会取消蓄力，可以继续后重新按住。
- 按住宠物拖动可以移动位置，松开时保存，重启后恢复。接了多块显示器时可以拖到任意一块屏幕，悬停按钮、“更多”和出游卡片跟随小汉所在的屏幕；拔掉显示器后会回到最近的屏幕。右键也可打开“更多”。暂时收起期间继续计时，需要停止计时时可先点「暂停陪伴」。

出游场景左上角显示地点，右上角「回桌面」返回透明宠物。底部可散步、扔球、照顾、换风景和打开更多。点「照顾」可喂饭、喝水、休息或上厕所。有需求时会在提示旁提供最急的一项操作。照顾期间散步停在原处，照顾完成后继续。换风景或回桌面会结束原场景中未完成的散步和扔球。喂饭、喝水等互动进行中，可等本轮完成再换风景。

扔球从“更多 → 扔球接回”进入 420 × 330 的接球小场景，打开时等待你操作。在场景内按住鼠标左键，抛物线旁的圆角半透明竖向力度条随按住时长由下向上填充，约 2 秒到满格；松手才抛出。力度条使用柔和绿金渐变、顶端光点和圆角百分比标签。轻点轻抛、长按抛远，抛物线高度和落点按 0–100% 力度连续变化，不再使用近／中／远按钮。蓄力时显示抛物线与落点预览，满格后保持等待松手。力度取自按住时长，不读取鼠标物理压力。

移出场景后松手、切换窗口、暂停或按 Esc 都可以取消蓄力。未蓄力时，按 Esc 或点右上角的返回按钮。若从公园或雪地进入接球，返回后会在同一地点续上原来的散步。从桌面打开接球时，返回按钮会带你回桌面。场景上方的标题区域可拖动窗口。

球飞出后落地弹跳，小汉从当前位置追过去，身体、球和阴影随距离缩小，叼回时逐渐变大。幼年、少年、成年及三套衣服都有专用的捡球、转身、叼球小跑和放球动作。每局约 10 秒，完成后会显示本次运行已接回的球数。开始一轮时会检查饱腹、水分、体力和如厕需求，途中出现的新需求会在下一轮检查。中途退出接球会取消未完成的抛球。

## 拔玩具

鼠标移到小汉身上，点「拔玩具」，再按空格开始。下方指针进入绿区时按一下空格，越靠近绿区中心，拉动幅度越大。踩中时红绳绷紧，小汉的头和肩被往前带一下，随后小汉会撑住前爪、压低后腿反拉。上方的圆点显示谁占上风，到达一端或满 7 秒时结束。

连续踩中会在上方显示连击，连击越高，拉力会小幅加成。每拍只认第一次按键，按早、按晚或漏拍会中断连击。结算时会显示本局最高连击。

打开其他窗口或暂停陪伴时会保留当前拍子，回到游戏可按空格继续。完成有有效拉动的一轮会增加心情和亲密度，结算后沿用 30 秒冷却。整局没踩中时可点「再试一次」。点「退出」或按 Esc 可收起游戏。

新版动图为上一级 `小汉-拔河连击.gif`，由 Windows 独立窗口录制，用测试按键演示了前后拉扯、3 连击和按早断连击。窗口通过 22 项检查，记录在 `work/desktop-qa/tug-combo/window`。单元测试通过 63 项，跳过 1 项 macOS 专用检查。检查覆盖连击加成、漏拍和时机错误，并核对三个年龄、三套衣服在两个发力方向的爪底位置和红绳接点。

## 跳支舞

桌面模式点「更多 → 跳支舞」，小汉会用当前体型和衣服跳一段 8 秒的舞。小汉先换脚侧步、压低肩膀再向前伸爪。猫咪在约第 4 秒从右侧踩步进场，稍晚一拍接动作。两只在约第 6.5 秒一起伸爪，随后落地收势。暂停陪伴会停在当前动作，恢复后从这一拍继续。按 Esc 可以提前结束。

参考[「声舞短片」Skill 的卡莎白模挑战拆解](https://github.com/hugh97803-web/shengwu-duanpian/blob/master/SKILL.md)，用 130 BPM 的同一条时间轴编排换脚、前伸定格、猫咪的错拍进场和舞台灯光，动作改编成四足版本。上一级的 `小汉和猫咪-八秒合跳.mp4` 使用原创节拍，`小汉和猫咪-八秒合跳.gif` 和本地桌面播放为无声动画。

猫咪沿用另一项目已确认的灰白长毛形象，透明动作素材为 `assets/dance_cat.png`。素材生成提示词在项目的 `work/desktop-qa/dance`。本轮通过 66 项单元测试及 12 项 Windows 窗口检查，跳过 1 项 macOS 专用检查。帧截图、窗口检查记录及上一版回退副本位于 `work/desktop-qa/dance-v2`。

## 工作与休息提醒

默认按 **工作 60 分钟、休息 10 分钟** 提醒。到时在小汉下方显示提示，“更多”首页出现“5 分钟后提醒”；剩余时间和提醒开关在“更多 → 设置”。

工作时间根据 Windows 键鼠活动估计：无输入达到 1 分钟后停止累加，短暂离开保留此前的工作时间；连续无输入满 10 分钟后重新开始一轮。休息中途操作键鼠，连续休息时长会重新计算。只读取最近输入的空闲时长，不读取或保存按键、鼠标位置、文本；看屏幕但不操作时，程序无法区分阅读和离开。电脑挂起造成的采样间隔不算作工作，退出、关闭提醒或暂停陪伴会清空本轮提醒计时；开关保存，计时不跨程序重启保存。此计时与成长所用的有效陪伴时间分开。

打字时双爪轮流敲两个大按键，火光使用已选择的 **B 动漫烈焰**。大小随最近的按键频率平滑变化：慢打只在脚边有小火，正常输入在身体两侧，快速连打可升到肩部附近；放慢后逐渐收小。极快输入也有最大尺寸限制。停手约 0.8 秒后停止敲键，余火继续收小熄灭。火光只跟随打字，鼠标点击不触发。桌面模式通过收小表现熄灭，出游模式同时淡出透明度。关闭打字/火光、暂停或进入其他互动会立即收起火光。互动动画优先于打字。仅在内存保留最近一次键盘活动的时间、事件计数和衰减频率估计，不保存按键、文本或历史，不联网；按键频率不等于文字输入字数。

## 饥饿、缺水和疲劳

饱腹、水分或体力低于 25 时，待机改用对应的两帧状态：饥饿时低头期待、缓慢眨眼；缺水时低头轻吐舌喘气；疲劳时趴下、眼皮变沉。三种年龄、三套衣服都有独立素材，桌面和出游都生效。多个数值偏低时，先显示数值最低的需求；相同时优先水分、饱腹、体力，提示列出所有偏低项目。更多面板同时标注“偏低”。

虚弱待机优先于跟随打字和等待下一球时的走动；照顾及已经进行的互动动画优先。数值低于 12 时，不能开始新的散步、扔球或拉扯玩具，仍能喂食、喝水、睡觉。轻度偏低仍可玩耍。互动完成才补充对应数值，恢复到 25 或以上时解除该项状态；另有需求偏低则继续显示相应状态。提示不是定时弹窗，不强迫点击，不添加离线扣减、疾病或死亡机制。

## 上厕所

小汉在程序运行、未暂停时逐渐产生如厕需求，键鼠暂时没有输入也会累计；关闭和暂停期间不累计，电脑挂起不补算整段时间。约 2 小时开始提醒并左右换脚、抬头等你；约 3 小时显示“很急”，暂时不能开始新的散步、扔球或拉扯玩具。计时最多累计到 4 小时。这是桌面宠物的游戏节奏。

悬停九宫格或“更多 → 照顾状态”中的“上厕所”均可操作，距离上次完成满 30 分钟后也能提前处理。动作持续约 8 秒，中间用小屏风遮挡；完成才清空需求、增加 2 点心情，中途取消不会清空需求或获得奖励。幼年、少年、成年及三套衣服均有着急状态，桌面与出游均可使用。

“更多”显示如厕舒适度和“舒适／想上厕所／很急”。如厕需求与饥饿、口渴、疲劳一起按舒适程度选择待机动画，相同时依次优先水分、饱腹、体力、如厕；提示列出全部偏低需求。旧存档首次从无需上厕所开始，新计时保存为 `toilet_seconds`，重启后保留已累计时间，不补算关闭时间。

## 成长和存档

幼年初始解锁；累计有效陪伴达到 20 小时且亲密达到 20 解锁少年，累计达到 40 小时且亲密达到 55 解锁成年，即每累计 20 小时解锁下一阶段，亲密度门槛沿用。规则写在 `model.py` 中。

在“更多 → 成长”选择“小 · 幼年”“中 · 少年”“大 · 成年”。已解锁形态可来回选择，未解锁按钮禁用。下方圆角进度条显示下一阶段的陪伴进度百分比，以及还差的小时、分钟和亲密度：幼年到少年按 0–20 小时计算，少年到成年按 20–40 小时计算。时间满格但亲密不足时仍显示所缺亲密度；全部解锁显示“已完成”。进度跟随最高解锁阶段，切回较小体型不重置。解锁时提示，但不会强制改变当前形态；互动进行中暂不能换形态，结束后可切换。动作、打字、衣服、出游和扔球均按所选形态显示，选择保存到存档，重启后保留。

已解锁阶段与当前选择分别保存为 `unlocked_stage`、`stage`。旧存档没有解锁字段时，以原成长阶段作为已解锁阶段，保留旧版已获得的少年/成年，不因新时长重新锁住；未解锁的后续阶段按新的累计时长判定。

电脑无输入超过 5 分钟、暂停、程序关闭期间不累计有效陪伴。关闭期间不掉状态。解锁不会撤回，选择较小形态不重置成长进度。正餐、喝水等互动有短暂冷却；完成后才改变状态，取消不会得到奖励。轻拍会让她收耳委屈并降低心情和亲密，摸摸可安抚。

存档在 `data/pet.json`，操作完成、换装、拖动窗口、退出以及运行中每 30 秒保存。较旧的存档会沿用默认位置，第一次拖动后记住新位置。损坏的存档会明确报错。备份或迁移时保留整个文件夹。

微信会把接收文件夹里的文件标成只读，保存时会先清除小汉自己存档文件的只读属性；杀毒软件或索引程序短暂占用存档时，替换最多尝试 3 次。仍然写不进去时（例如便携版放在 Program Files 或只读位置），第一次弹窗说明原因和处理办法，之后只在小汉下方提示；退出时会询问是否不保存直接退出。分享给朋友时，请对方把“小汉”文件夹解压到桌面或 D 盘等普通文件夹。

## 版本与远程更新

当前版本写在 `version.py`。Windows 便携版启动 15 秒后检查一次更新，之后每 6 小时检查一次，读取公开仓库 `xingtianxiang/xiaohan-desktop` 最新 Release 里的 `latest.json`（版本号、下载地址、SHA-256 和大小）。检查只发出普通的下载请求，不上传任何数据；连不上时不打扰使用，只在设置页记下结果。

发现新版本时提示一次，“更多”首页出现“更新”按钮。点了才下载；下载完核对大小和 SHA-256，解压到程序旁的 `.update` 文件夹，保存进度后退出。随后由新版本替换 `小汉.exe`、`_internal` 等程序文件，`data` 不动，替换失败会恢复旧版并提示，完成后重新打开小汉，新版本启动时删除 `.update`。“更多 → 设置 → 自动检查更新”可以关闭，设置页显示当前版本和上次检查结果。源码运行和 Mac 版不检查更新。

发布新版本：

1. 修改 `version.py` 的版本号，写好 `work/release-notes/<版本>.md`。
2. 按 `work/packaging-requirements.txt` 在 `work/portable-build/venv` 安装依赖，运行 `work/build_portable.py`，安装包输出到 `outputs/releases/<版本>/`。
3. 运行 `work/check_portable.py`，解压后启动两次做检查。
4. 提交并推送源码，再运行 `python work/publish_release.py --notes-file work/release-notes/<版本>.md`。脚本确认源码已推送、安装包由这份源码构建、版本号没发布过，然后创建 GitHub Release，并以匿名方式下载 `latest.json` 和安装包进行核对。
