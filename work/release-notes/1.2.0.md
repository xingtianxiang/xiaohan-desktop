## 小汉 1.2.0

- 跳支舞换成用即梦生成的那支舞：汉堡穿黑色机车背心、带闪电翼，14 秒，带原声。跳舞时小汉的窗口会变成一块小舞台，跳完回到原位。鼠标移到舞台上会出现“× 停止”，按 Esc 也能停；暂停、收起或退出时舞会直接结束。原来小汉和猫咪的合跳已经去掉。
- 鼠标互动：
  - 用鼠标在小汉周围画一整圈，她就会上台跳舞。
  - 鼠标在她头上移动，或在身上来回轻划几下，就是摸摸。她会耳朵往后贴、头往上顶、摇尾巴，四只脚不离地。
  - 鼠标停在她头上时，头会跟着鼠标轻轻动；鼠标在附近时她会看向鼠标。鼠标在她身体另一侧停半秒，她会轻轻一跳转过身。
  - 看向鼠标可以在“更多 → 设置”里关闭。程序只在待机时读取鼠标当前位置，不记录、不保存。
- 跳舞会按系统音量放音乐，在办公室用时注意音量。

### 安装

已经装了 1.1.0：在“更多”里点“更新”，进度会保留。

第一次安装：下载 `xiaohan-windows64-1.2.0.zip`，完整解压到桌面或 D 盘等普通文件夹，不要放在微信、QQ 的接收文件夹里，然后打开“小汉”文件夹，双击“小汉.exe”。

适用于 Windows 10/11 64 位。程序没有代码签名，Windows 可能提示未知发布者。Mac 版这次没有更新。舞蹈画面由即梦 AI 生成，左上角保留“AI生成”标识；音乐取自抖音视频原声。
