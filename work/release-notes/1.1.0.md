## 小汉 1.1.0

- 新增自动更新：有新版本时，“更多”里会出现“更新”按钮，点一下自动下载、校验并替换程序，进度保留。可在“更多 → 设置”关闭自动检查。
- 修复放在微信接收文件夹里时保存提示“拒绝访问”的问题。存档失败时不再每 30 秒弹窗，退出时可以选择不保存直接退出。
- 接了多块显示器时，可以把小汉拖到任意一块屏幕。
- 包含拔河连击、跳支舞和退出告别。

### 安装

下载 `xiaohan-windows64-1.1.0.zip`，完整解压到桌面或 D 盘等普通文件夹，不要放在微信、QQ 的接收文件夹里，然后打开“小汉”文件夹，双击“小汉.exe”。

从旧版升级：先退出旧版小汉，把旧文件夹里的 `data` 文件夹复制到新解压的“小汉”文件夹里，进度就会保留。从这个版本开始，以后可以在程序里直接更新。

适用于 Windows 10/11 64 位。程序没有代码签名，Windows 可能提示未知发布者。Mac 版这次没有更新。
