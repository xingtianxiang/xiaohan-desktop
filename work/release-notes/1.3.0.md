## 小汉 1.3.0

- 体力会自己恢复了：小汉安静待着时慢慢回体力，你离开电脑 5 分钟她会趴下打盹，回得更快，醒来会告诉你恢复了多少。点“睡觉”仍然最快。“更多 → 照顾状态”里写明了这几种恢复方式。
- 新增四个小游戏，越玩越快、会输，并记录最高分：
  - 接零食：跟着鼠标接骨头和饼干，躲开巧克力和葡萄。
  - 猜球在哪：盯住藏着球的桶，桶会越换越快，后面变成四个。
  - 跨栏敏捷赛：按空格或按住鼠标起跳，矮栏轻按、高栏长按。
  - 爪印记忆：照着亮起的顺序点爪印，每关多一步。
  鼠标移到小汉身上，点「小游戏」打开列表（拔玩具也在里面）。每局有得分就加心情和亲密，同一个游戏 30 秒领一次奖励。
- 打字时小汉坐在一把小键盘后面，左右爪轮流敲键。你按的键会变成键帽从键盘上冒出来。键帽可以在“更多 → 设置 → 显示按下的键”关闭；开着时只在内存里看最近几个按键，不保存。输入密码时键帽也会显示，开会共享屏幕前可以先关掉。
- 打字动作由即梦（Seedream 5.5）AI 生成，三套衣服、三个年龄各一组。

### 安装

已经装了 1.1.0 或 1.2.0：在“更多”里点“更新”，进度会保留。

第一次安装：下载 `xiaohan-windows64-1.3.0.zip`，完整解压到桌面或 D 盘等普通文件夹，不要放在微信、QQ 的接收文件夹里，然后打开“小汉”文件夹，双击“小汉.exe”。

适用于 Windows 10/11 64 位。程序没有代码签名，Windows 可能提示未知发布者。Mac 版这次没有更新。
